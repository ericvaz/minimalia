# The Minimalia name and logo

The code in this repository is free software under the GNU General Public License, version 3. That licence covers the code. It does not cover the name "Minimalia", the program names built on it, such as Minimalia Folio and Minimalia Shelf, or the Minimalia logo and icons. Eric Vaz keeps all rights in these.

I want people to know when they are using the real Minimalia. So:

- You may use the name to refer to Minimalia, for example in a review, a tutorial, a link or a statement that your work is "based on Minimalia".
- You may build and run Minimalia from this repository for yourself, unchanged, under its own name.
- If you distribute a modified version, give it a different name and icon, and do not suggest that I made or endorse it. Saying "a fork of Minimalia" in its description is fine.
- Please do not use the name or logo in a product, company name, domain name or app store listing without asking me first.

If you are unsure, open an issue and ask. I am glad to say yes to most reasonable uses.
